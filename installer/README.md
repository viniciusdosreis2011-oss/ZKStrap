# ZKStrap Installer

O `ZKStrapInstaller.exe` e compilado automaticamente pelo GitHub Actions. Nao e necessario rodar BUILD_INSTALLER.bat.

Link fixo do instalador:

`https://github.com/viniciusdosreis2011-oss/ZKStrap/releases/download/installer-latest/ZKStrapInstaller.exe`

Sempre que os arquivos do installer mudarem, o workflow recompila o EXE e substitui o asset desse mesmo link.
